# Graph Maker(グラフ作成ツール)

GoogleスプレッドシートやExcelで集計したデータを貼り付けるだけで、レポートや資料用のグラフ画像を作成できるツールです。
プログラミングの知識がなくても、このREADMEを上から順に読めば導入・起動・確認ができます。

## 1. 準備するもの

- Windows 10 または 11 のパソコン
- インターネット接続(初回のセットアップ時のみ必要です)
- このツールのフォルダ一式(このREADMEが入っているフォルダ)

## 2. Pythonのインストール

このツールは「Python」というプログラムの実行環境の上で動きます。まだ入っていない場合はインストールします。

1. ブラウザで https://www.python.org/downloads/ を開きます。
2. 「Download Python 3.x.x」のボタンから、Windows用のインストーラをダウンロードします(3.11以上)。
3. ダウンロードしたファイルをダブルクリックしてインストーラを起動します。
4. **最初の画面の下のほうにある「Add python.exe to PATH」に必ずチェックを入れてください。**
   これにチェックを入れないと、コマンドプロンプトから `python` が使えません。
5. 「Install Now」をクリックしてインストールを進めます。
6. 完了したら「Close」で閉じます。

既に別バージョンのPythonが入っている場合は、そのままで問題ありません(3.11以上であれば動作します)。バージョンが古い場合は、上記の手順で新しいバージョンを追加でインストールしてください。

## 3. Pythonのインストール確認

1. キーボードの「Windowsキー」を押し、「cmd」と入力して「コマンドプロンプト」を開きます。
2. 次のコマンドを1行ずつ入力してEnterキーを押します。

   ```
   python --version
   ```

   ```
   pip --version
   ```

3. それぞれ次のように表示されれば成功です(バージョン番号は多少違っても問題ありません)。

   ```
   Python 3.11.8
   pip 23.3.1 from ...
   ```

### うまく表示されない場合

- **何も表示されない/「'python' は認識されていません」と出る**
  → PATHの設定が反映されていません。一度コマンドプロンプトを閉じて開き直してください。それでも直らない場合は、Pythonを再インストールし、「Add python.exe to PATH」に必ずチェックを入れてください。
- **Microsoft Storeの画面が開いてしまう**
  → Windowsの「アプリ実行エイリアス」でPythonが無効化されている可能性があります。「設定」→「アプリ」→「詳細なアプリ設定」→「アプリ実行エイリアス」を開き、「python.exe」「python3.exe」をオフにしてください。
- **`python` の代わりに `py` を使う**
  → 環境によっては `python --version` の代わりに `py --version` を使うと動作する場合があります。以降のコマンドの `python` を `py` に読み替えてください。

## 4. ライブラリのインストール

1. コマンドプロンプトで、このツールのフォルダへ移動します(フォルダのパスは自分の環境に合わせて置き換えてください)。

2. 必要なライブラリを一括インストールします。

   ```
   pip install -r requirements.txt
   ```

3. 完了すると、最後に次のような表示が出ます。

   ```
   Successfully installed streamlit-... plotly-... kaleido-... pandas-... openpyxl-...
   ```

### 任意:仮想環境(venv)を使う場合

他のPythonツールと環境を分けたい場合は、次の手順で専用の環境を作れます。

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

以降、このフォルダで作業する際は `.venv\Scripts\activate` を実行してから `graph.bat` やコマンドを使ってください。

## 5. ライブラリのインストール確認

1. 次のコマンドでインストール済みのバージョンが表示されることを確認します。

   ```
   pip show streamlit plotly kaleido pandas
   ```

2. 次のコマンドを実行し、「OK」と表示されれば準備完了です。

   ```
   python -c "import streamlit, plotly, kaleido, pandas; print('OK')"
   ```

## 6. 画像出力の確認

グラフ画像の書き出しには「Kaleido」というライブラリを使います。Kaleidoのバージョンによっては、裏側でGoogle Chromeが必要になることがあります。

1. まずは何もインストールせずに、後述の「8. 起動と終了」の手順でツールを起動し、サンプルデータからPNG画像を1枚出力してみてください。
2. 正常にダウンロードできれば、追加の作業は不要です。
3. 画像作成時に `Chrome` や `Kaleido` に関するエラーが表示された場合は、次のいずれかを行ってください。
   - パソコンにGoogle Chromeをインストールする(https://www.google.com/chrome/ )。
   - コマンドプロンプトで `pip install -U kaleido` を実行し、最新版に更新する。

## 7. フォントの配置

グラフや画面で日本語が文字化けしないよう、「Noto Sans JP」というフォントの利用を想定しています。

1. https://fonts.google.com/noto/specimen/Noto+Sans+JP から「Get font」→ ダウンロードします。
2. ダウンロードしたZIPを展開し、`.ttf` ファイルをこのツールの `fonts/` フォルダにコピーします。
3. Windows標準の「游ゴシック」「メイリオ」がインストールされていれば、Noto Sans JPを配置しなくても日本語は文字化けせずに表示されます。より見た目を統一したい場合にNoto Sans JPを配置してください。

## 8. 起動と終了

1. このツールのフォルダを開き、`graph.bat` をダブルクリックします。
2. 黒いウィンドウ(コマンドプロンプト)が開き、Pythonとライブラリの確認が行われます。
3. 問題がなければ自動的にブラウザが立ち上がり、`http://localhost:8501` が開きます(開かない場合は、表示されたアドレスをブラウザに直接入力してください)。
4. **終了するときは、開いたままの黒いウィンドウを閉じてください。** ブラウザのタブを閉じるだけでは裏側のプログラムは終了しません。

## 9. 基本的な使い方

1. `samples/sample_yearly.tsv` をメモ帳やExcelで開き、中身をコピーします。
2. ツールの画面上部にある入力欄に貼り付け、「読み込む」ボタンを押します。
3. 自動で「2. プレビュー」タブに切り替わり、表のプレビューと列の型(数値・文字・年)が表示されます。データを入れ直すときは「1. データを入力」タブに戻ります。
4. 「グラフ設定」で、レイアウト(1段・上下2段・左右2列・2×2)を選び、段ごとにグラフ種類(下の「描けるグラフの種類」を参照)、X軸、Y軸(系列)を選びます。
   - 複数段のときは、段ごとのタブ(上段・下段など)で設定します。「X軸を共有」「上段の高さ」「段の間隔」で並び方を調整できます。
   - 桁の違う系列(件数と累積件数、売上と利益など)は「右軸に表示する系列」で右側の軸に割り当てます。
   - 「軸の詳細設定」で、軸タイトル・最小/最大・目盛間隔・単位・数値の書式を指定できます。
5. 「スタイルとプレビュー」の左側で、系列の色・文字の色・グラフ枠の色・目盛線の色・文字サイズ・凡例の位置などを変更します。変更は右側のプレビューにすぐ反映されます。
   - 色タブの「カラーパレット」で、配色をまとめて選べます。「配色」(標準・色覚多様性に配慮・ビビッド・落ち着いた・パステル・モノクロ)は項目ごとに色をはっきり分けます。「グラデーション」(青・緑・オレンジ・紫・赤・グレーなど)は系列の数に合わせて濃い色から薄い色へ順に色を振るので、積み上げ棒に向いています。パレットを選んだあと、系列ごとに色を変えることもできます。
   - 凡例・ラベルタブの「値ラベルを表示する段」で、段ごとに値ラベルのオン/オフを切り替えられます。
6. 「画像出力」で幅・高さ・倍率を指定して(既定はGoogleスライドの横幅の半分にあたる 480×360 px、倍率2です)「PNG画像を作成」を押すと、実際の出力画像が画面に表示されます。
   - 画像を右クリックして「名前を付けて画像を保存」で保存できます。「画像をコピー」を選べば、GoogleスライドやWord、PowerPointにそのまま貼り付けられます。
   - 「ダウンロード」ボタンを使うと、指定したファイル名で保存できます。
   - 倍率2は、貼り付け先で文字がぼやけないよう画素数を2倍にしています。貼り付けたあと、画像を半分の大きさに縮めてください。

ほかのサンプル(`samples/` フォルダ)も同様に試すことができます。それぞれに向いたグラフは、下の「描けるグラフの種類」を参照してください。

### 1行目に年が並ぶ表(1行が1系列)の場合

`samples/sample_sales_rows.tsv` のように、1行目に年が横に並び、各行が「連結売上高」「営業利益」などの系列になっている表もそのまま貼り付けられます。
ツールが自動で判定し、行と列を入れ替えて「X軸=年、系列=各行」のグラフにします。
判定が合わない場合は、プレビュー欄の「データの向き」で「1行が1系列」「1列が1系列」を手動で選び直してください。

### 描けるグラフの種類

| グラフ種類 | 向いているデータ・用途 | 使い方のポイント | 試せるサンプル |
| --- | --- | --- | --- |
| 棒(縦棒・横棒) | 年別の件数、企業ランキング | 横棒は表の1行目が一番上に並びます(ランキング向け)。 | `sample_yearly.tsv`、`sample_ranking.tsv` |
| 積み上げ棒 | 企業別件数の分野ごとの内訳 | 「Y軸(系列)」に選んだ列を積み上げます。 | `sample_cross.tsv` |
| 100%積み上げ棒 | 企業ごとの分野の構成比 | 各棒の合計を100%として構成比で表示します。 | `sample_cross.tsv` |
| 折れ線 | 件数の推移、売上・利益の推移 | 値ラベルを付けても枠線に重ならないよう、上側に余白をとります。 | `sample_sales_rows.tsv` |
| 棒+折れ線 | 件数(棒)と累積件数・比率(折れ線) | 「折れ線にする系列」で、どの系列を折れ線にするかを選びます。 | `sample_yearly.tsv` |
| 円・ドーナツ | 企業別・地域別のシェア | 「項目の列」と「値の列」を1つずつ選びます。「ドーナツにする」で中央を空けられます。色は項目ごとに変えられます。 | `sample_ranking.tsv` |
| ウォーターフォール | 売上の前年からの増減、増減の要因分解 | 「表の値の意味」で「各時点の水準」(前年との差を自動計算)か「増減量」を選びます。 | `sample_sales_rows.tsv` |
| パレート図 | 上位の項目への集中度(上位何社で全体の何割か) | 件数の多い順に棒を並べ、累積比率を右軸の折れ線で重ねます。80%の目安線を引けます。 | `sample_ranking.tsv` |
| バブル | 年別×分野別の件数の推移、企業×分野のクロス集計 | 「行の項目の位置」で、表の行の項目(年や企業)を横軸・縦軸のどちらに並べるかを選びます(既定は横軸)。選んだ列が反対側の軸に並び、件数が円の大きさになります。濃い色の円の数字は白で表示します。 | `sample_cross.tsv` |
| ヒートマップ | 企業×分野、年×分野のクロス集計 | バブルと同じ選び方で、件数を色の濃さで表します(「行の項目の位置」の既定は縦軸)。色の種類(モノクロ印刷向け・色覚多様性に配慮した配色も)を選べます。 | `sample_cross.tsv` |
| ツリーマップ | 大分類・小分類などの階層ごとの構成 | 「項目の列」に最も細かい分類の列を選ぶと、表でその左にある分類の列が上位の階層になります。「分類コードの先頭文字から自動作成」を選ぶと、A01B → A / A01 / A01B のようなコードから階層を作ります。 | `sample_category.tsv` |
| ライフサイクル図 | 市場や分野が成長期・成熟期・衰退期のどこにあるかの判断 | 「年の列」「件数(量)の列(縦軸)」「参加数(企業数など)の列(横軸)」を選びます。年の順に点を結び、最後の年は矢印で示します。右上へ伸びていれば成長期、左下へ戻っていれば衰退期の目安です。 | `sample_lifecycle.tsv` |

棒・折れ線・棒+折れ線では、「右軸に表示する系列」を使って左右2軸のグラフにできます。
グラフの種類は段ごとに選べるので、例えば上段=棒、下段=パレート図のように組み合わせられます。

## 10. トラブルシューティング

| 症状 | 原因と対処 |
| --- | --- |
| `ModuleNotFoundError: No module named 'streamlit'` など | ライブラリが未インストールです。「4. ライブラリのインストール」の `pip install -r requirements.txt` を実行してください。 |
| `Port 8501 is already in use` | 既にツールが起動しています。開いたままのコマンドプロンプトのウィンドウを探して閉じるか、パソコンを再起動してから `graph.bat` を実行し直してください。 |
| ツールを更新した直後に `ImportError: cannot import name ...` と表示される | 起動中のツールが更新前のファイルを覚えたままになっています。コマンドプロンプトのウィンドウを閉じて、`graph.bat` から起動し直してください(ブラウザの再読み込みだけでは直りません)。 |
| 画面やグラフの日本語が文字化けする | 「7. フォントの配置」を確認してください。また、ブラウザを最新版に更新してみてください。 |
| PNG画像の作成でエラーになる | 「6. 画像出力の確認」を参照し、Google Chromeの導入または `pip install -U kaleido` を試してください。 |
| `graph.bat` を実行しても真っ黒な画面がすぐ閉じてしまう | フォルダ内で`graph.bat`を右クリックし、「編集」でファイルを確認するか、コマンドプロンプトを先に開いてから `graph.bat` のパスを直接入力して実行し、表示されるメッセージを確認してください。 |

## 11. アップデート方法

ツールのファイルが更新された場合や、ライブラリを追加した場合は、次の手順を行ってください。

1. 新しいツール一式を、今のフォルダの内容と入れ替えます(`templates/` フォルダに保存したスタイルがある場合は残しておいてください)。
2. コマンドプロンプトでツールのフォルダに移動し、ライブラリを再インストールします。

   ```
   pip install -r requirements.txt --upgrade
   ```

3. `graph.bat` を実行し、正常に起動することを確認します。
